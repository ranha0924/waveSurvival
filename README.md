# Wave Survival FPS

순수 HTML/CSS/JavaScript로 구현한 1인칭 슈팅 서바이벌 게임. 외부 라이브러리 없이 Canvas 2D 레이캐스팅(Wolfenstein 3D 스타일)으로 의사 3D 렌더링을 수행한다.

## 실행 방법

브라우저는 `file://`에서도 동작하지만 일부 기능(Pointer Lock 등) 호환성을 위해 로컬 서버 권장.

```bash
python3 -m http.server 8080
# 브라우저에서 http://localhost:8080 열기
```

## 조작법

| 키 | 동작 |
|----|----|
| W A S D | 전후좌우 이동 |
| 마우스 | 시점 회전 |
| 좌클릭 | 사격 (홀드로 자동 사격) |
| R | 재장전 |
| Shift | 달리기 (스태미나 소모) |
| 1 ~ 4 | 무기 교체 |
| ESC | 일시정지 |

## 핵심 기능

- **레이캐스팅 엔진**: DDA 알고리즘으로 벽 거리 측정, zBuffer 기반 스프라이트 가림 처리
- **무기 4종**: 권총 / 샷건 / 기관총 / 저격총 (각자 데미지·연사·퍼짐·관통 특성)
- **적 5종**: 졸개 / 돌진형 / 탱커 / 원거리 / 보스 (5웨이브마다)
- **로그라이크 업그레이드**: 웨이브 클리어마다 3개 중 1개 선택 (공격/방어/유틸)
- **콤보 시스템**: 2초 이내 연속 킬 ×1.5 → ×2 → ×3
- **헤드샷 보너스 ×2**, 웨이브 클리어 보너스 (웨이브 × 500)
- **사운드**: Web Audio API로 모든 효과음 합성 (외부 파일 없음)
- **HUD**: 체력/스태미나 바, 미니맵, 무기·탄약, 콤보, 웨이브 배너, 피격 비네트

## 파일 구조

```
index.html         메인 페이지, 캔버스 + HUD DOM
style.css          HUD/오버레이 스타일
js/main.js         게임 루프, 입력, 상태 머신, 웨이브 매니저
js/raycaster.js    DDA 레이캐스팅 + 스프라이트 빌보드 렌더링
js/map.js          24×24 아레나 데이터, 충돌, 시야선
js/player.js       이동, 사격, 재장전, 콤보, 업그레이드 모디파이어
js/weapon.js       4종 무기 정의
js/enemy.js        적 AI, 스폰, 웨이브 구성
js/audio.js        Web Audio API 효과음
js/ui.js           HUD 갱신, 미니맵, 메뉴, 업그레이드 카드, 1인칭 무기 그리기
```
